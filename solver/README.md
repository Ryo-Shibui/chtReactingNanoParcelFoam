# chtReactingNanoParcelFoam: build sources

This directory contains only the solver build sources and native build scripts.
From a sourced supported OpenCFD OpenFOAM environment, run:

~~~sh
./Allwmake
~~~

See the [repository usage guide](../README.md) and its `tutorials/` directory
for complete physical examples, gas-property sources and validation results.
For a standalone source installation, the public guide is:
https://github.com/Ryo-Shibui/chtReactingNanoParcelFoam

Keep cases, generated meshes, logs and plots outside this build directory.
